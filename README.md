# Kagisho High School Digital Parent Communication System

## Project
Digital Parent Communication System for Kagisho High School.

## Group
ELEV8

## Module
ITC327W – Work-Integrated Learning

## Institution
Central University of Technology

## Project Description
The system is designed to improve communication between Kagisho High School
and parents/guardians through a Flutter mobile application and an ASP.NET
web application supported by a shared Supabase backend.

## Technologies
- Flutter
- ASP.NET
- Supabase
- GitHub
