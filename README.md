# Kagisho High School Digital Parent Communication System

## Project

Digital Parent Communication System for Kagisho High School.

## Group

ELEV8

## Module

ITC327W — Work-Integrated Learning

## Institution

Central University of Technology (CUT)

## Project Description

The Kagisho High School Digital Parent Communication System is an Information Technology project developed by the ELEV8 group for the ITC327W Work-Integrated Learning module at the Central University of Technology (CUT).

The project aims to improve communication between Kagisho High School and parents or guardians. Traditional communication methods, including physical letters sent through learners and WhatsApp groups, can result in important school information being missed, delayed or overlooked.

The proposed system provides a digital platform through which authorised school staff can publish announcements and upload school documents, while parents and guardians can access relevant school information through a mobile application.

## Project Objectives

- Improve communication between the school and parents or guardians.
- Provide convenient access to school announcements and digital letters.
- Help parents stay informed about important school events and notices.
- Enable authorised school staff to publish and manage school communications.
- Make school announcements and supporting documents accessible in one place.

## Proposed Solution

The system consists of a Flutter mobile application for parents and guardians and an ASP.NET web portal for authorised school staff. Both applications use shared Supabase backend services and database functionality to support communication and information sharing.

## Parent/Guardian Mobile Application

- Register and log in.
- View school announcements.
- Access announcements relevant to their grade.
- Open school letters and supporting documents.
- Receive notifications about important announcements.
- View previous announcements.
- Log out securely.

## School Staff Web Portal

- Log in using authorised staff credentials.
- Create and publish school announcements.
- Enter announcement titles, descriptions, categories, dates and priorities.
- Select the intended audience, including all parents or a specific grade.
- Upload school letters and supporting documents.
- Edit or remove published announcements.
- View basic information about announcement access.

## Technologies

- Flutter — Parent and guardian mobile application.
- ASP.NET — School staff web portal.
- Supabase — Shared backend services and database.
- GitHub — Source control, documentation management and group collaboration.

## System Architecture

The system connects the parent and guardian mobile application, the school staff web portal and shared Supabase services. Parents and guardians use Flutter to access announcements and school documents, while authorised school staff use the ASP.NET web portal to publish and manage school communications.

Supabase supports the shared storage and retrieval of system information required by the applications.
