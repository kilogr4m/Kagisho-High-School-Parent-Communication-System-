UML Diagrams

This folder contains the UML diagrams for the Kagisho High School Digital Parent Communication System.

Required Diagrams

1. Use Case Diagram: Shows the system actors and the functions available to parents/guardians and school staff.
2. Sequence Diagram — Flutter and Supabase: Shows interactions between the parent mobile application and Supabase.
3. Sequence Diagram — ASP.NET and Supabase: Shows interactions between the school staff web portal and Supabase.

Purpose

These diagrams illustrate the system’s functionality, user interactions, and communication flows. They must align with the approved system requirements and system architecture.

The final diagrams and their editable source files should be stored in this folder.
