# ASP.NET Web Application

## Project Description
This folder contains the ASP.NET web application for the Kagisho High School Digital Parent Communication System.

## Purpose
The application allows school staff to manage and publish important school announcements and communication for parents and guardians.

## Main Functionalities
- School staff login
- Create and publish school announcements
- View school announcements
- Edit and update announcements
- Remove announcements
- Upload school letters and documents
- Manage announcement priority and target audience

## Technologies
- ASP.NET
- C#
- Supabase

## Backend Integration
The web application uses the shared Supabase backend to save, retrieve and update school announcement information.
