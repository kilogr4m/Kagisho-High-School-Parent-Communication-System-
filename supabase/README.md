# Supabase Backend

## Project Description
This folder contains the Supabase backend setup and database resources for the Kagisho High School Digital Parent Communication System.

## Purpose
The backend provides shared database services that allow the Flutter mobile application and ASP.NET web application to store, retrieve and manage system information.

## Main Functionalities
- Store parent, guardian and school staff information
- Store school announcements
- Manage uploaded school letters and documents
- Store notification information
- Record announcement viewing information
- Support shared data access between the mobile and web applications

## Technologies
- Supabase
- PostgreSQL
- SQL

## Backend Integration
Supabase provides the shared backend used by both the Flutter mobile application and ASP.NET web application to access consistent system information.

## Source Code
The Supabase database scripts and backend setup resources will be maintained in this folder.
