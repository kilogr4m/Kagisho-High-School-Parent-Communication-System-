Software Requirements Specification (SRS)

This folder contains the updated Software Requirements Specification for the Kagisho High School Digital Parent Communication System.

Required Content

The updated SRS must combine the Phase 1 requirements and the Phase 2 system architecture and design documentation.

It should include:

* System architecture.
* UML Use Case Diagram.
* Both Sequence Diagrams.
* Entity Relationship Diagram (ERD).
* Flutter and ASP.NET interface designs.
* Design-alignment documentation.
* Microsoft Project schedule screenshot.
* Working GitHub repository link and original editable design-source links.

Purpose

The SRS provides the consolidated requirements and design documentation for the project.

The final SRS PDF should be stored in this folder.
