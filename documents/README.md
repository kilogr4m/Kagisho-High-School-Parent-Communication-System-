Project Documentation

This folder contains all the official documentation, technical designs and project management records for the Kagisho High School Digital Parent Communication System, developed by Group ELEV8.

It serves as a central location for organising and accessing the documents produced throughout the system analysis, design, development and project implementation phases.

Folder Contents

* Architecture: System architecture diagrams and supporting documentation.
* Database: Entity Relationship Diagrams (ERD) and database design documentation.
* Interfaces: User interface designs for the Flutter mobile application and ASP.NET web portal.
* Project Management: Project schedules, Microsoft Project files and progress tracking records.
* SRS: Software Requirements Specification and related requirements documentation.
* UML: Use Case Diagrams and Sequence Diagrams illustrating system interactions and processes.

Purpose

The purpose of this folder is to maintain a structured and accessible collection of project documents, ensuring that all technical designs, requirements and project records are organised in one place for development, collaboration, assessment and future reference.
