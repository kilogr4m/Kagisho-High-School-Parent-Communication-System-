System Architecture

This folder contains the system architecture for the Kagisho High School Digital Parent Communication System.

System Components

* Flutter: Parent and guardian mobile application.
* ASP.NET: School staff web portal.
* Supabase: Shared backend services and database.

Purpose

The system architecture diagram illustrates the main system components, their responsibilities, and how the Flutter application and ASP.NET web portal connect to the shared Supabase services.

The final architecture diagram and its editable source file should be stored in this folder.
