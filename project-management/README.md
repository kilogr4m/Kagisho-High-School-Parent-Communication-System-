# Project Management

This folder contains the Microsoft Project planning
and tracking documentation for the Kagisho High School
Digital Parent Communication System.

## Project Management Deliverables

- Microsoft Project Plan (.mpp)
- Gantt Chart
- Tracking Gantt
- Resource Allocation
- Project Timeline and Milestones

## Purpose

To document project scheduling, resource allocation,
task dependencies, and progress tracking throughout
the project development lifecycle.
