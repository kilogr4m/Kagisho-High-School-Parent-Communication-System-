Database Design

This folder contains the database design for the Kagisho High School Digital Parent Communication System.

Entity Relationship Diagram (ERD)

The ERD should show:

* Relevant database entities and fields.
* Primary keys (PKs) and foreign keys (FKs).
* Relationships and cardinalities between entities.
* How the database supports the parent mobile application and school staff web portal.

Purpose

The database design must support the approved system requirements and the information used by both applications.

The final ERD and its editable source file should be stored in this folder.
