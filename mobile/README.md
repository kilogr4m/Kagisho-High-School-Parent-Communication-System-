# Flutter Mobile Application

## Project Description
This folder contains the Flutter mobile application for the Kagisho High School Digital Parent Communication System.

## Purpose
The application allows parents and guardians to access important school announcements and communication digitally.

## Main Functionalities
- Parent and guardian registration and login
- View school announcements
- Access uploaded school letters and documents
- Receive important notifications
- View previous announcements
- Logout

## Technologies
- Flutter
- Dart
- Supabase

## Backend Integration
The mobile application uses the shared Supabase backend to access authorised system information.
